# 量子力学练习册 · V1 内测

[打开 GitHub Pages](https://liu2233ru.github.io/quantum-practice/)

按格里菲斯、施罗特《量子力学概论》原书第 3 版中文版的 12 章目录学习。章节页列出教材正文起始页。补充专题包括算符与表象进阶、量子测量与信道、传播子与路径积分，以及光与原子的相互作用。

- **章节练习**支持练习本章全部题目、仅做未做题或单题练习。
- **自由组卷**支持跨章节、难度和题型筛选，题量可选，支持随机或按章节题序。题量允许时优先照顾每个有候选题的章节。
- **逐题反馈**提供提示与推导解析。单选和多选按正确选项集合判定。推导题可保留草稿并对照解析自评。
- **错题本**自动记录失误次数和待订正状态，支持批量复练，做对后转为已订正。
- **学习数据**保存在当前浏览器。可以继续未完成练习，或通过菜单导出、导入 JSON 备份。

V1 共有 92 道原创练习，其中 76 道单选或多选题，16 道推导自评题。教材用于确定学习顺序与知识边界。随附的英文解析手册是第 2 版。

## 补充阅读

- 算符与表象进阶：Shankar《量子力学原理》第 2 版第 1 章，Cohen-Tannoudji 等《量子力学》第一卷第 2 章。
- 量子测量与信道：格里菲斯第 3 版 §12.3，Cohen-Tannoudji 等《量子力学》第一卷第 4 章的密度矩阵补充材料。
- 传播子与路径积分：Shankar《量子力学原理》第 2 版第 8 章。
- 光与原子的相互作用：Cohen-Tannoudji 等《量子力学》第二卷第 13 章关于原子与电磁波相互作用的补充材料。

## 本地运行

在项目目录运行 `python -m http.server 8000`，打开 `http://localhost:8000`。本项目可直接托管于 GitHub Pages，使用仓库根目录作为发布源。公式由随站点托管的 KaTeX 渲染。

运行 `npm test` 检查题库结构、公式、组卷、判分及备份。
