# 量子力学练习册 · V1.2 内测

[打开 GitHub Pages](https://liu2233ru.github.io/quantum-practice/)

按格里菲斯、施罗特《量子力学概论》中文版原书第 3 版的 12 章练习。章节页列出教材正文起始页。另有算符与表象、量子测量与信道、路径积分、光与原子相互作用四个补充专题。

- **逐步解析与得分点**。推导题按小问列出列式、代入、计算和结论，每一步旁标明参考分值。小问分值由步骤分相加，题目分值体现推导长度、计算量和难度。可逐小问录入自评分，支持半分。
- **自由组卷恰好 100 分**。按章节、题型与难度限定范围，可从可行题量中挑选。保留题库原分值，优先抽教材大题。找不到精确组合时显示可达到的最高分。章节练习和单题练习依所选题目计算总分。
- **228 道题**，包括 96 道推导大题、56 道判断题和 76 道选择题。教材题标注版本或卷次、题号或节号，已核对的页码可在题目页查找。解析和评分点由独立推导编写。
- **学习记录**保存在当前浏览器，旧练习沿用原分值。支持备份、导入和确认清空。未得满分的大题与答错的客观题进入错题本，复练得满分后标记为已订正。

## 教材来源

- 格里菲斯、施罗特《量子力学概论》原书第 3 版，主线各章。随附的英文解析手册属于第 2 版，题号用中文版第 3 版核对。
- Shankar《量子力学原理》第 2 版，数学基础与路径积分题。
- Cohen-Tannoudji、Diu、Laloë《量子力学》第一、二卷，算符、测量和光与原子相互作用题。

## 本地运行

在项目目录运行 `python -m http.server 8000`，打开 `http://localhost:8000`。项目使用静态文件，直接从 GitHub Pages 的仓库根目录发布。公式由随站点托管的 KaTeX 渲染。

运行 `npm test` 检查题库、公式、精确组卷、分项评分和旧分值兼容。
